# Project instructions

Keep source and documentation in English. This project is offline with respect
to robot hardware: never import an SDK or connect to a robot. Dataset network
access is explicit through discover/fetch, never on import or in unit tests.
Preserve source data and sibling repositories. Record source URLs, revisions,
checksums, missing fields, derived labels, and simulation assumptions. Do not
equate accessible, downloaded, retargeted, and physics-validated data.
Do not count overlapping versions or crops as independent demonstrations.
Stop new transfers before disk free space falls below 50 decimal GB.
Never weld, teleport, or overwrite the moving object's state during physical
validation. Save failed attempts as well as successes.
